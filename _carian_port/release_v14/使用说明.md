# 卡利亚大剑 → 巨凶斧 3.6.2：法环原版辉石大剑 + 法环原版特效（显卡播放全部粒子）与音效

## 内容

- **剑**：《艾尔登法环》原版辉石大剑 s88310，包括法环剑身自带的雕花护手、剑身和法环的发光握柄（握柄一直到剑柄末端）。
  - 位置由 `Scripts\fit.lua` 的三个数字决定：`guardZ=31.3`、`tipZ=312.07385`、`gripMinZ=-104.2205`。
  - 剑身数据由 `toolchain\build_er_blade.py` 生成：`er_blade.lua`、`er_grip.lua`、`er_blade_curves.lua` 和两张法环贴图。
- **特效**：法环原版伟哉卡利亚的 13 个 FXR（见下文"来源与还原方式"）。
  - 全部粒子由显卡播放：`toolchain\bake_gpu.py` 烘焙出 `gpu_player.lua`、`gpu_<id>.lua` 和材质包里的数据贴图。
  - 召唤纹章（FXR 510120）走 CPU 画法（`gpu_player.CPU_VISUALS`）。
- **材质**：自制材质包 `ProjectPBZ\Content\Paks\~mods\zzz_CarianBrutalAxe_P`，由 `toolchain\build_fx_container.py` 生成。
  - 支持逐粒子的 FXR 颜色、半透明混合、空气扭曲、径向模糊和渐隐的剑身。
  - 着色器内嵌在材质包里，不会每次启动都编译。原因见 `verification\pso_cache\README.md`。
- **音效**：法环原版音效，由 `toolchain\extract_grandeur_sounds.py` 从本机法环提取，按原版的循环方式播放，跟随游戏音量。
  - 包里没有 exe。游戏启动时，`SoundHelper\CarianSound.ps1` 让 Windows 自带的 PowerShell 现场编译 `CarianSound.cs`，由 `CarianSound.vbs` 隐藏启动；没有 VBScript 时用 `CarianSound.cmd`。
  - 放技能时，巨凶斧原版的音效静音。
- **其他**：斩击结束后剑消失。放技能时，GPU 网格的逐帧参数写在自定义图元数据里，拖影段合成一个批次，主线程开销较小。

## 法环原版特效的来源与还原方式

- 从本机《艾尔登法环》提取伟哉卡利亚的 13 个 FXR：
  - 450021–450023：三段剑身
  - 450030–450032：召唤 / 升段
  - 450024–450026：挥砍拖尾
  - 450027–450029：落地
  - 510120：卡利亚纹章
- 用 `original_runtime` 里的 FXR 解释器（`fxr_engine.lua`）以 60 Hz 离线模拟，记录每个可见粒子的位置、尺寸、颜色、图集帧和透明阈值。
  - 超出预算的发射器均匀抽稀，保留下来的粒子按 √(抽稀比) 提亮。
  - 一段、二段的剑气细线不抽稀，整体渲染成序列帧（`toolchain/bake_aura.py`）。
- 贴图全部来自法环原贴图，合成到一张 2048 图集中。多层贴图按原层色和层透明度合成，透明阈值按原曲线折算为溶解淡出。

## 安装

见玩家看的 `卡利亚大剑_巨凶斧_安装说明.txt`：

1. 关闭游戏。
2. 把压缩包里的全部内容解压到游戏根目录（有 platform、ProjectPBZ 的那个文件夹），同名文件选替换。

- 包里自带 UE4SS 加载器（PBZ 配置），模组靠 `enabled.txt` 启用，不改 mods.txt。
- 材质包是 `ProjectPBZ\Content\Paks\~mods\zzz_CarianBrutalAxe_P` 的 .pak、.utoc、.ucas 三个文件。

## 卸载

退出游戏（音效播放器会随之退出），删除 `platform\steam\ue4ss\Mods\CarianBrutalAxe`，以及 `ProjectPBZ\Content\Paks\~mods\zzz_CarianBrutalAxe_P.pak/.utoc/.ucas`。

## 可调参数（`Scripts/config.lua`）

括号里是默认值。config.lua 里没写的项用代码里的默认值。

- `sizeProfile`：剑身尺寸方案。
  - `'original'`（默认）：法环原版比例，长 1/1.731/2.462、宽 1/2.083/3.167。
  - `'v12'`：长度 1/1.5/2.2、宽度 1/1.35/1.75。
- `fxEnabled`（true）：设为 false 时关闭全部法环特效，只保留剑身。
- `fxAura` / `fxAuraIntensity`（true / 0.6）：一段、二段剑气的开关和亮度。设到 1.0 时剑身会被剑气的亮芯盖住。
- `fxExposure` / `fxMaxEmissive`（0.035 / 3.2）：法环 HDR 亮度到游戏发光值的换算，以及高光上限。上限过高时，二段升段的闪光会触发游戏自带的镜头光晕（屏幕另一侧出现一个淡色六边形）。
- `sigilOnStageUp`（false）：设为 true 时，每次升段也闪一次纹章。原版只在召唤时闪一次。
- `fxMaxQuads`、`fxMaxRibbonQuads`（300、960）：同屏粒子面片和拖尾段数的上限，低配机器可以调小。
- 材质：`customMaterials`（'auto'）、`fxRadialBlur`（1，径向模糊强度，0 关闭）、`fxRefraction`（0.004，空气扭曲强度，0 关闭）、`fxWhiten`（0.7，最亮的核心变白的程度）。
- 显卡粒子：`fxGPU`（true；false 时改用 CPU 画法）、`fxGPURigMaxSize`（0，跟随剑身的 GPU 面片尺寸上限，0 为原版尺寸）。
- CPU 画法下跟随剑身的面片尺寸上限：`fxRigMaxSize`（220 厘米）。剑气的收拢程度烘在贴图里，由 `toolchain/bake_aura.py` 的 `SQUEEZE` 和 `SWIRL` 控制。
- 气流与拖影亮度：`fxAirflowExposure`（0.21，升段气流和落地光柱）、`fxWispExposure`（0.1，升段气流加色层）、`fxWispBlendExposure`（1，气流半透明底层）、`fxTrailExposure`（0.1，拖影）。
- 星点与火花：`fxSparkleDensity`（4，招式中星点和落刀火花是原版的几倍，1–5）、`fxSparkExposure`（0.1，剑气和落刀的火花）。
- 拖影形状：`fxTrailMaxSeconds`（2.0）、`fxTrailOrientation`（true，沿剑身）、`fxTrailFacing`（1，侧对镜头时转向镜头）、`fxTrailEnd`（true，挥完即停）、`fxTrailNearFade`（{60, 300} 厘米，近镜头淡出）、`fxTrailOneBin`（true，放在一个批次）。
- 落刀与排序：`fxImpactAnchor`（'player'，落刀从角色脚下铺开）、`fxImpactSortPriority`（10，落刀特效画在游戏尘土之上）、`fxBlendSortPriority`（-1，半透明层画在发光层下面）。
- 音效播放器：`sfxHost`（'exe' 或 'powershell'；不写时有 exe 就用 exe，懒人包里没有 exe）、`sfxLauncher`（'vbs' 或 'cmd'；不写时有 VBScript 就用 .vbs）。

## 仍是近似的部分

- 原引擎的随机序列、Hermite 曲线采样、柔深度和折射扭曲没有逐位还原。扭曲是读取身后画面后偏移的近似（本游戏关闭了引擎的扭曲通道）。
- 法环的 HDR 曝光与泛光无法直接对应到 PBZ，亮度经过一次经验换算并压缩了高光。
- 不用自制材质时（`customMaterials=false`），游戏自带材质不认顶点颜色和 `Main_Color`：逐粒子亮度用倍频档位配合面积微调，淡出时尺寸会轻微变化，颜色只随贴图亮度变化，也没有径向模糊和扭曲。
- 剑气每 0.6 秒循环一次；收拢程度、环绕方向和只保留一半是按反馈设定的，并非原版参数。
- 原事件在下劈触地时于 DummyPoly 80 生成 SFX 400，但法环全部 220 个 SFX 容器里都没有这个文件。同族的 430–434、440–442 都只含 WindForce（只推动草和布料、没有可见粒子），所以 400 很可能也只是一阵风，没有画面可还原。
- 没有按受击材质分派命中特效。
- 沿用巨凶斧的原生动作和攻击判定，不改伤害、范围、精力、次数和存档。放大的剑刃仍可能穿入地面或墙体。
- 音效的空间感只有左右声像和远近音量，没有 Wwise 的混响、遮挡和优先级管理。
- 音量跟随游戏的总音量和音效音量滑块，但不跟随"后台播放声音"设置：切到其他窗口时，正在播放的法环音效会继续播完。
