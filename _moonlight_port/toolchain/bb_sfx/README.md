# 读《血源诅咒》的特效（月光 1.3、1.3.1）

《血源诅咒》的特效文件是 FXR 版本 2（`FXR\0` + `0x00020000`，64 位，小端）。它和黑魂 1 的 FXR1 是同一套结构，但布局有几处不同，SoulsFormats 的 FXR1 读不了。这里的脚本都只读文件，结果写在忽略的 `bloodborne_source\sfx\` 下。

## 格式（`bbfxr.py`）

- 文件头：
  - 0x08：根节点偏移（varint）；
  - 0x10：重定位表的位置，0x14：指针个数，0x18：节点个数；
  - 表里先是所有指针字段的位置，再是所有节点的位置，各 8 字节。
- varint：一个 int32，后面跟 4 字节 0（或 `0xCDCDCDCD`）。
- 根节点 133，共 96 字节：133、特效编号、0、0、96、容器、状态表指针、状态个数、一个 141 节点的指针。
- 容器，32 字节：节点指针表的指针、节点数、第二个计数、4 个标志字节、4 字节空、修饰器指针。
  - 与 DS1R 不同，没有 action data 指针，动作的参数全部作为节点列出。
- 状态（24 字节）、转移（16 字节）、动作（varint 动作号加容器，40 字节）与 FXR1 相同。
- 节点：
  - 1 整数，2 整数数组，7 浮点，70 时间，79 两个整数，81 两个浮点，85 两个时间；
  - 5/6 整数曲线，11/12 浮点曲线，13 带切线的浮点曲线，19 颜色曲线，21 带切线的颜色曲线；
  - 37 调用特效，38 调用动作（都带容器）；
  - 新增：40 贴图编号；82 子节点加相对随机幅度（值 ×(1±r)）；83 两种 RGBA 之间随机；141/142/143/146/147 整数加内嵌容器。
- 曲线：时间数组和值数组分开存。带切线的曲线先存全部关键值，再存两组切线（角度）。
  - 插值方式是统计全部 DLC 特效得出的：5、11、19 线性；6、12、20 循环线性。
- 检查：每读一个指针都要在指针表里，每个节点都要在节点表里，读完检查两张表是否都已用完。
  - 250030、250035 完整读出；
  - DLC 的 49 个特效里 28 个完整读出，其余含有节点 15、84 或 149，还没读。

## 动作

字段名的来源：
- 动作编号和大部分字段顺序与 DS1 的 FXR1 一致，名字取自 SoulsFormatsNEXT 的 `FXR1/FXActionData.cs`。
- 血源比 DS1 多出的字段，按 DS3 的 FXR3 里同一动作的字段顺序对上，含义取自 EvenTorset/fxr 的说明文档（实测过的 DS3/法环行为）。两者的结尾部分逐项相同：整数 8、泛光开关、泛光颜色、图层组合方式、6 个 −1 的距离。
- 每个对应关系都用血源本体 3624 个特效文件（3428 个不同编号）的统计核对过（`verification\public_1.3.1\README.md`）。
- 这些含义没有在血源里实测。

初始方向（32 [13]）与 DS3 的 InitialDirection 相同：
- 0：按发射器形状；
- 1/2：世界上/下；3：世界 +Z；
- 4/5：局部上/下；6：局部 +Z。

血源 881 个盒形发射器只出现 0、1、2、3、4、6。一个 12×0×13 m 的水平面、粒子慢慢上升的环境特效，取的是 1。

两个统计结果支持把 32 [7] 读成粒子缩放：
- 点精灵的发射器 [7] 都很小（0.0075–0.05，中位 0.02），而点精灵自己的大小多为 2.5，相乘正好是几厘米的光点；
- 序列帧公告板里 [7] 与 [8] 不同的 116 个，有 109 个的 [10] 为 0（不统一缩放）。

## 脚本

- `bbfxr.py <fxr> [--json out] [--quiet]`：读整个特效并打印树和覆盖报告。
- `fxr_probe.py`、`fxr_words.py`：看原始结构（按 8 字节一格显示，标出指针、节点和被指向的位置）。
- `curve_survey.py <fxr>...`：统计各类曲线的关键帧形态，用来判断插值方式。
- `find_assets.py s15000 s01035 ...`：资源在哪个特效包里。
- `dds_preview.py <tex dir> <sheet.png>`：DDS 转 PNG 并拼预览。
- `tae_effects.py`、`find_tae_sfx.py`：从动作事件（`BbAssetBridge tae` 的输出）找出生成的特效编号。

特效包、贴图和模型用 `BbAssetBridge` 的 `bnd`、`tpf`、`flver` 命令取出。移植用的完整流程在 `..\build_moonlight_transform_fx.py`。
