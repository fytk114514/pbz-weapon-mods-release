# 影之刃零武器模组：卡利亚大剑 / 神圣月光大剑

《影之刃零》（Phantom Blade Zero）的两个武器外观模组，做成解压即用的懒人包。只换外观（卡利亚还换音效），不改动作、伤害和判定，也不碰存档。

**下载：[Releases](https://github.com/fytk114514/pbz-weapon-mods-release/releases/latest)**

## 卡利亚大剑 → 巨凶斧 3.6.2

使用煞气兵器巨凶斧（默认左 Ctrl，按住蓄力）时，召唤出《艾尔登法环》战技"伟哉卡利亚"的辉石大剑。剑、特效和音效都来自法环原版：蓄力升段时剑按原版比例变大并闪光，召唤、升段、挥砍和落地都带原版特效和音效，最后一刀之后剑会消失。

## 神圣月光大剑 → 亡命斩马刀 1.1

把亡命斩马刀换成《血源诅咒》的神圣月光大剑，模型和贴图由原版文件转换。平时是缠着布条的剑，重攻击后变成青蓝发光的剑刃，轻攻击切回；防御＋重击蓄力时剑身的雾光聚集、变亮。

## 安装

1. 关闭游戏。
2. 在 Steam 库里右键"影之刃零"→ 管理 → 浏览本地文件，打开游戏根目录（能看到 platform、ProjectPBZ、Engine 三个文件夹）。
3. 把压缩包里的全部内容解压到这个文件夹，提示同名文件时选"替换"。
4. 照常从 Steam 启动游戏。

- 两个包可以都装，里面的加载器文件完全相同。
- 不需要运行任何脚本，也不用改 mods.txt。
- 每个压缩包里都有一份详细的安装说明，卸载方法也在里面。

适用：影之刃零 Steam 版（CL-302256_JKS-17280，Unreal Engine 5.7.4）。游戏更新后如果模组不生效，需要等模组更新。
